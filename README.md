# moonwalk
- This is a proof-of-concept x86 binary obfuscator using relatively novel techniques and kernel image mapper

## License
MIT [LICENSE](LICENSE)

## Details
- Branch scattering, xor/mov/shl/shr obfuscation
- Ability to map kernel images into VM memory regions for testing
- If RNG seeded properly, will generate unique or one-off instruction sequences to reduce chances of signature detections
